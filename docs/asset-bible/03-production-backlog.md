## Recommended first four coherent vertical slices

1. **Lumish Imperial market:** registry hall, chapel, fortified market arcade, civic granary, road assets and ordinary work scenes; contrast heartland vs frontier.
2. **Zuraldi mountain caravan village:** matriarch council hall, terraced farms, caravan unloading shelf, watchhouse and cliff-road support.
3. **Stonehold mine gate and industrial avenue:** massive mountain gate, forge, smelter, ore lift, rail cart and enough air/water system to be believable.
4. **Grukmar mixed border market:** goblin stilt homes and docks plus orc upland halls and trade routes, same realm but differing societies.

Run two scene concept images before converting objects to meshes. Each vertical slice needs recognizable ordinary homes, signature civic form, livelihood/logistics, terrain transitions, props, NPC professions, season and wear overlays.

## Tracking statuses

`planned → hero-approved → multiview-approved → blockout → modeled → PBR-ready → optimized → runtime-integrated → scene-reviewed`. Separate `loreStatus` (`published` vs `repo-authored` vs `proposal`) from `modelStatus`. Review data licenses and geometry budgets before runtime asset inclusion.
